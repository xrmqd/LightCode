# GitHub Copilot в LightCode

## Как начать

1. Открой обычный файл с кодом в проекте.
2. Нажми **Copilot: Off** в правой части строки состояния или выбери
   **LightCode → GitHub Copilot → Sign In…**.
3. Подтверди включение. На macOS LightCode при необходимости скачает официальный
   компонент GitHub для твоего процессора и проверит контрольную сумму архива.
4. Нажми **Copy Code and Open GitHub**, вставь одноразовый код на странице GitHub
   и войди в аккаунт с доступом к Copilot. Используется подписка этого аккаунта,
   в том числе полученная через GitHub Education; отдельный ключ API не нужен.
5. Начни печатать. Через короткую паузу подходящее продолжение появится серым
   текстом прямо в редакторе.

Доступность подсказок и лимиты определяет GitHub. Чат, выбор модели и подсказки
правок в других местах файла в этой версии не добавлены.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Принять подсказку | **Tab**; если открыт обычный список автодополнения, можно принять Copilot через **Option+Enter** |
| Скрыть подсказку | **Esc** |
| Запросить подсказку вручную | **Option+\\** или **Trigger Suggestion** |
| Выбрать другой вариант, если он есть | **Option+[** / **Option+]** |
| Остановить подсказки на 10 минут | **Pause for 10 Minutes** |
| Возобновить досрочно | **Resume Suggestions** |
| Отключить для языка открытого файла | **Disable for …** в меню статуса |
| Выключить и остановить сервер | **Disable Copilot** |
| Выйти из GitHub | **Sign Out** при включённом Copilot |

Смена файла, выделения или текста отменяет неподходящие подсказки. Принятую
подсказку можно отменить обычной командой Undo.

Copilot по умолчанию выключен. После включения официальный сервис GitHub
получает контекст подходящих открытых файлов для генерации подсказок.
LightCode не отправляет приватные файлы, служебные поля редактора, файлы с
удалённых проектов и файлы размером больше 1 МБ. На паузе запросы подсказок
останавливаются; вход в аккаунт сохраняется.

## Настройки

Параметры находятся в пользовательском разделе Copilot файла настроек:

    {
      "copilot": {
        "enabled": false,
        "disabled_languages": [],
        "debounce_ms": 300,
        "server_path": null
      }
    }

Пауза действует только в текущем сеансе, выключение и исключения по языкам
сохраняются. Параметр server_path позволяет указать абсолютный путь к уже
установленному серверу GitHub. Автоматическая установка поддерживается для
Apple Silicon и Intel Mac.

Интеграция LightCode написана на Rust и использует
[официальный GitHub Copilot Language Server](https://github.com/github/copilot-language-server-release).
